# Art provenance

PortraitSource.png and PortraitAlternateSource.png are unchanged copies of the user-supplied golden profile and Workbench references. Runtime UV rectangles sample only the portrait artwork; the reference card, typography, progress, glass and lighting are never displayed as a flattened component. Both portrait variants are supplied reference art, not new commissioned characters.

Display.ttf: static Oxanium SemiBold from Sevmeyer, SIL Open Font License; license alongside this file. https://github.com/sevmeyer/oxanium/blob/master/fonts/ttf/Oxanium-SemiBold.ttf

Body.ttf: Roboto Regular from the installed Unreal Engine Slate font assets.

All frame geometry, glass, labels, masks, progress, lights and motion overlays are editable native Slate layers generated by PlayerProfile.h.
